# TXT 阅读器 MVP 产品设计

## 产品方向

做一个轻量、易用的 TXT 阅读网站，用户通过浏览器打开即可使用，无需安装桌面应用。支持导入本地文字书籍、舒服地阅读，并在下次打开时继续阅读。

第一版只支持 TXT，优先保证中文显示正常、阅读流畅和进度保存可靠。目标用户是阅读本地 TXT 小说或其他纯文字内容的个人用户。

## 核心使用流程

导入 TXT 文件 → 在书架打开书籍 → 阅读并调整显示设置 → 关闭 → 再次打开并继续上次阅读。

## 主要功能

| 功能 | MVP 范围 |
| --- | --- |
| 文件导入 | 支持本地 TXT 文件，处理常见的 UTF-8、GBK 编码；导入失败、空文件或格式不支持时给出明确提示。 |
| 简单书架 | 以文件名作为书名，展示阅读进度，按最近阅读排序；支持打开和移除书籍。移除只影响阅读器内的记录与副本，不删除用户原始文件。 |
| 正文阅读 | 使用上下滚动方式，保留原文段落和换行；长文本阅读应保持流畅。 |
| 阅读设置 | 支持字号、行距、浅色与深色主题；设置在下次打开时保留。 |
| 进度保存 | 自动保存每本书的阅读位置，重新打开后恢复；调整字号或行距后，仍能定位到原文附近。 |

## 界面方向

以书架和阅读页为两个主要界面。书架方便快速找到最近阅读的书；阅读页以正文为主，设置入口保持简洁，减少对阅读的干扰。

## 首版边界

- 不做目录、章节识别和章节跳转。
- 不支持 EPUB、PDF、漫画等其他格式。
- 不做账号、云同步、书城、在线书源。
- 不做 AI 功能、翻译、复杂笔记和阅读统计。
- 第一版聚焦单设备、同一浏览器使用，书籍、进度和设置保存在当前浏览器本地，不上传书籍内容。清除网站数据会丢失这些记录，更换浏览器或设备不会自动同步。

## 验收与测试场景

| 场景 | 预期结果 |
| --- | --- |
| 分别导入 UTF-8、GBK 中文 TXT | 中文及段落正常显示，无明显乱码。 |
| 导入空文件、不支持的文件或无法读取的文件 | 给出清晰提示，不出现无法退出的空白阅读页。 |
| 打开长篇 TXT 并连续滚动 | 正文可正常浏览，无持续卡顿；具体文件规模在实现阶段确定。 |
| 修改字号、行距和主题后重新打开 | 设置保留，正文显示正确。 |
| 阅读中途关闭并重新打开同一本书 | 恢复到上次阅读的原文附近。 |
| 调整字号或行距后继续阅读 | 不因排版变化跳到无关内容。 |
| 阅读多本书后查看书架 | 最近阅读排序正确，每本书的进度独立保存。 |
| 刷新页面或关闭浏览器后，使用同一浏览器重新访问 | 书架、阅读设置和各书阅读进度保留，无需重新导入。 |
| 浏览器存储不可用或保存失败 | 明确提示保存失败，不误报导入成功或进度已保存。 |
| 从书架移除书籍 | 书架记录移除，用户原始 TXT 文件仍然存在。 |

## 后续方向

先根据实际使用反馈改善阅读体验，再考虑搜索、书签及其他格式支持，不在本次 MVP 中展开。

平台确定为网站；具体技术栈在实现方案中选择。
